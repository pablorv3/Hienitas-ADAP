## 📝 Descripción del Proyecto

Este repositorio contiene el desarrollo del proyecto de la asignatura basado en el Método del Caso. El trabajo consiste en el análisis, diseño y especificación de un sistema software de gestión para la empresa **Turbine**, abarcando desde la toma de requisitos inicial con el cliente hasta el modelado de la arquitectura y la interfaz gráfica de usuario.

El proyecto se divide en tres entregas iterativas, gestionadas mediante una adaptación de la metodología ágil Scrum.
